Google Sheets Integration (Cloud Data Storage)

เชื่อมต่อกับ Google Spreadsheet ผ่าน Apps Script เพื่อบันทึกข้อมูลแบบเรียลไทม์ และซิงค์ข้อมูลระหว่างหลายเครื่อง

📊 คลิกที่นี่เพื่อเปิด Google Spreadsheet (Master Database)
📖 ขั้นตอนการติดตั้ง Google Apps Script (คลิกเพื่อดู)
  1. สร้าง Google Spreadsheet ใหม่ใน Google Drive (ตั้งชื่อตามต้องการ)
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. คัดลอกโค้ดทั้งหมดจากไฟล์ google-apps-script.js ไปวางใน Apps Script Editor
  4. กด การทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New deployment)
  5. เลือกประเภท: เว็บแอป (Web App) | การเรียกใช้: ฉัน (Me) | สิทธิ์เข้าถึง: ทุกคน (Anyone)
  6. กด Deploy, อนุมัติสิทธิ์ (Authorize), แล้วคัดลอก Web App URL มาวางในช่องด้านบน
